## 👋 About Me

I'm **Muhammad Ashhad**, a passionate mobile application developer from **Pakistan** 🇵🇰, crafting fast, beautiful, and scalable cross-platform apps with **Flutter**.

- 🔭 &nbsp;I'm currently building **[DubiCars](https://play.google.com/store/apps/details?id=com.dubicars.dubicars)** — one of the UAE's leading automotive marketplaces.
- 💙 &nbsp;I specialize in **Flutter, Firebase, REST APIs, State Management, CI/CD**, and clean **App Architectures**.
- 🌱 &nbsp;I'm always sharpening my craft — from pixel-perfect UI to production-grade release pipelines.
- 🤝 &nbsp;I love turning complex problems into simple, elegant, and delightful mobile experiences.
- 📫 &nbsp;Reach me at **[ionwork08@gmail.com](mailto:ionwork08@gmail.com)** — happy to talk Flutter, architecture, or anything mobile.
- 📄 &nbsp;Explore my experience on **[LinkedIn](https://www.linkedin.com/in/muhammad-ashhad/)**.
